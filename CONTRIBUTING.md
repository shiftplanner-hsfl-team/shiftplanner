# Mitarbeit an ShiftPlanner

## Branches
- `main` ist geschützt; Änderungen nur per Pull Request mit 1 Review.
- Namen: `feature/REQ-08-plan-erzeugen`, `docs/use-cases`, `fix/<kurz>`

## Commits
- Nachricht beginnt mit der ID: `REQ-08: Prioritätssortierung ergänzt`
- Jede Person committet selbst und regelmäßig.

## Pull Requests
- Im PR das Issue verlinken: `Closes #<Nummer>`
- Ein anderes Teammitglied reviewt.

## Coding-Guidelines
- Folgen (PEP 8 als Basis, Details werden im Team vereinbart und begründet).
