## 1 Vorgehensmodell und Praktiken:

We work in a hybrid: a Scrum frame, XP practices and a Lean Startup feedback loop. Why? (small team, real customer feedback needed, a runnable product every 2 weeks)
Scrum: 2-week sprints as GitHub milestones (Sprint 1: 02.11.–15.11.2026). Since the P1 feedback, deliberately decoupled from the presentation dates.
XP: coding standards with automatic checks in GitHub Actions (#22, PR #28), every change through a pull request with review, at least one test per acceptance criterion.
Lean Startup: three feedback rounds with real planners and employees (FB-01 to FB-15), from which we derive decisions (E-01 to E-03), see docs/feedback/feedback.md.
Tracking: two boards (product and management, since the P2 feedback), issues with estimates.
Literature at the end: Schwaber & Sutherland (2020) The Scrum Guide; Beck & Andres (2004) Extreme Programming Explained; Ries (2011) The Lean Startup.
